## Introduction

This encyclopedia aims to be one of the most detailed public repositories of military organizational knowledge. It draws from open sources and presents information in a clear, structured, and visual manner.

**Key features:**
- Rank tables with NATO codes (OF/OR)
- Main headquarters and historic forts
- Unit hierarchy (squad → army group)
- Images of flags, insignia, and key installations
- A single very long timeline of major wars and military events across history
- Comparative analysis across nations

### How to Navigate
1. Use the **Timeline** for historical context.
2. Dive into individual country pages for ranks, HQs, and details.
3. Use comparative ranks for quick cross-referencing.

## Enabling the Clean Public Website (GitHub Pages)

To turn this into a polished website:
1. Go to the repository **Settings → Pages**
2. Under "Build and deployment", select **Deploy from a branch**
3. Choose branch **main** and folder **/ (root)**
4. Save. Within a minute or two the site will be live at:
   **https://pheoisherenow.github.io/Military-Encyclopedia/**
