## Introduction

This encyclopedia aims to be one of the most detailed public repositories of military organizational knowledge. It draws from open sources (Wikipedia, official defense websites, NATO publications, etc.) and presents information in a clear, structured, and visual manner.

**Key features:**
- Rank tables with NATO codes (OF/OR)
- Main headquarters and historic forts
- Unit hierarchy (squad → army group)
- Images of flags, insignia, and key installations (via Wikimedia Commons links)
- Comparative analysis across nations

### How to Navigate
1. Start with the country pages for deep dives.
2. Use the comparative ranks for quick cross-referencing.
3. Check the organization section for general doctrine.
